# TaxMate 중간 발표 슬라이드

카카오테크캠퍼스 4기 부산대 4팀 — 자영업자 카드 지출 비용처리 판정 서비스 중간 발표 웹 슬라이드입니다.

- 보기: GitHub Pages 주소 또는 `index.html`을 브라우저로 열기
- 조작: `→` / `Space` 다음, `←` 이전, `F` 전체화면, 모바일은 스와이프
- 특정 슬라이드로 바로 가기: 주소 끝에 `#번호` (예: `#10`)
- PDF로 저장: 브라우저 인쇄 → PDF 저장 (슬라이드당 1페이지)

수치는 2026-10-03 기준 팀 레포 `develop` 브랜치와 작업 기록을 근거로 했습니다.
